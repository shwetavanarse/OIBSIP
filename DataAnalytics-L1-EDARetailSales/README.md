   # EDA on Retail Sales Data
   
   Performed exploratory data analysis on the Superstore retail sales dataset 
   to uncover trends in sales, customer segments, product performance, and 
   the impact of discounting on profitability.
   
   ## Tools Used
   Python, pandas, matplotlib, seaborn, Jupyter/Google Colab
   
   ## Key Insights
   - Sales peak in Nov-Dec each year (holiday season)
   - Discounts above 40% often result in net losses
   - Technology and Furniture are the top revenue-generating categories
